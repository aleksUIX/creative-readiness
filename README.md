# Creative Readiness

Open-source module for **Live Event Ad Creative Readiness**: evaluate whether a creative is ready for a named live environment (policy, technical, operational), with identity and evidence that have a scope, a version, and an expiry.

Not an SSP, not an SSAI, not a transcode farm. Members embed the library. IAB Tech Lab Advanced TV draft v0.02 is the input; this repo is a reference implementation, not the standard.
