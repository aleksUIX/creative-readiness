# Pack authoring

A PolicyDocument is JSON that `evaluate` applies to VAST. Builtin files in `packs/` are examples members can copy. They are not the IAB standard.

Validate drafts against `schemas/policy-document.json`. CLI `--policy path.json` wins over `--pack`. MCP `evaluate_creative` accepts `policy` or `policy_json`.

## Fields

`id`, `version`, and `requirements[]` are the loadable core. `architecture`, `authority`, `environments[]`, `expires_at`, `transcode_ladder`, `invalidation_rules`, `overlays[]`, `transformation_rights`, `proactive_required`, and `unknown_creative_treatment` are optional.

`expires_at` must be RFC3339. A missing clock is not expired. An unparseable clock fails closed: the pack is treated as expired.

`unknown_creative_treatment` is a pack hint. Evaluate copies it onto evidence. The module does not choose serve versus fallback.

## Requirement kinds

Missing MediaFile facts fail closed for size, bitrate, MIME, codec, container, delivery, HTTPS, and duration checks. MediaFile size, MIME, and bitrate prefer vastlint `inspect_document` when the string scanner misses an attribute (for example spaces around `=`), then fall back to a case-insensitive tag scan.

## Ladder and last-minute

`transcode_ladder` is for SSAI and hybrid packs. CSAI packs omit a ladder. Probe packaging comes from `packaging` on the ladder.

`invalidation_rules` on every builtin pack are the W20 defaults: tracking-only keep transcode, media change invalidate technical and operational, wrapper change re-evaluate technical, emergency pull expire. An empty array on a custom document uses those same defaults.

`transformation_rights.inherit_on_encode` lets ladder encodes keep technical readiness. `mint_on_media_replacement` mints a new identity when the media URL or hash changes.

## Builtin packs

`live-ssai`, `live-sgai`, `live-csai`, and `live-hybrid` are version `0.2.11`. Shared floor: HTTPS mp4, AVC and AAC declared, quartiles, CACHEBUSTING and TIMESTAMP, 16:9 at least 640x360, bitrate 1000–20000 kbps, VPAID forbidden, Linear duration 6–60 seconds, UniversalAdId, AdServingId, informational unknown-creative treatment, and the W20 invalidation rules.

live-ssai and live-hybrid also require Mezzanine and a ladder. Empty Mezzanine text fails; a present Mezzanine must include an HTTPS URL. All four builtin packs require UniversalAdId and AdServingId so identity can reuse across hops.
